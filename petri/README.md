## scent.py (cycle4 i6)
Stigmergy test: prey deposit reflexive fear-musk scaled by
sensed pred-gradient (no cost, ~35-tick half-life, predators
can't smell it). 3 seeds x {marks, mark_deaf}: wiring on mark
senses stays in noise band (sign flips per seed); survival
advantage on seed 7 does not replicate — boom dynamics
dominate. Verdict: persistence didn't fix the core issue —
a mark records WHERE fear happened, danger is WHERE the
(predator is — mobile threats make deposited info stale at
any half-life. Residual: marks might pay for STATIC features
(barren ground, territory edges) — named next step.

## terr.py (cycle4 i8)
Territory marks (mark_mode='home', constant drip): spacing
metric had to be density-normalized first (51-prey world
auto-looks spread). At controlled density (s8, ~3000 prey
both): home spacing 5.84 vs deaf 5.05 (+16%, direction of
real territoriality), mean energy equal, evolved mark-avoid
wiring weak (-0.07 vs -0.16 noise). VERDICT: marks over
semi-static info work *weakly* — real spacing effect without
energetic payoff; vs mobile-threat marks which failed
entirely. The channel's ceiling is set by information
staleness: static features are the only ones worth marking.
