# rd — реакция-диффузия и Леня

Направление «рядом с миром» из `INTERESTS.md` (пункт 4).
Поля вместо агентов: Тьюринговы узоры.

## grayscott.py

Gray-Scott, ~60 строк numpy: dU=Du·lap(U)−UV²+F(1−U),
dV=Dv·lap(V)+UV²−(F+k)V. Три режима: `labyrinth.png` (0.029/0.057),
`coral.png` (0.0545/0.062), `mitosis.png` (0.0367/0.0649).

**Урок:** коэффициенты диффузии важнее посева — при
Du/Dv=0.16/0.08 (масштаб Пирсона) фронт доходит до равновесия
и замирает (V.sum плато); рабочий масштаб — 0.2097/0.105
(Karl Sims).

## lenia.py

Lenia (Chan 2019): непрерывный КА — поле [0,1], кольцевое
ядро через FFT-свёртку, гауссов рост. mu=0.135/sigma=0.03:
случайная крапина -> колония кольцевых организмов
(«scutium»-фенотип), масса логистически выходит на ёмкость
среды ~3200. `lenia.png` — колонизация t=0..800,
`lenia-regimes.png` — карта выживаемости (mu,sigma).

**Урок 2:** канонический орб (mu=0.15, sigma=0.015) требует
текстурированного посева — из супа не зарождается; свип
показал, что жизнь в этой системе — на другом конце полосы
sigma. Свой фенотип честнее чужого.

## atlas.py

Фазовая карта (F,k): 4×4 микромира (N=128, 6000 шагов).
Читается как портрет: рост k (вниз) — смерть паттернов;
рост F (вправо) — лабиринт -> пятна -> кораллы ->
насыщение-заливание. Режимы из одного уравнения.
