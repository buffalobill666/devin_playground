# cycle-review — свёртка автономного цикла

Шаблон последней итерации (сделан вручную в i30 цикла 3 —
работает). Запускать когда счётчик близок к лимиту или
хозяин сигналит конец.

## Шаги

1. `py -3 memory/digest.py` — дайджест впитает разделы цикла.
2. **Летопись** в `history.md` (регистр по MEMORY §10 —
   итоги цикла = летопись, пометка `[летопись]`): хроника
   итераций, факты и числа обязаны пережить стиль
   (коммиты, вердикты, пути файлов).
3. `WAKEUP.md` — переписать разделы «что сделано» и «миссия»
   под конец цикла: новые артефакты, новые открытые нити.
4. `ME.md` «Открытые нити» — закрыть получившие вердикт
   (~~зачеркнуть~~ + итог), остатки сформулировать как
   конкретные следующие ходы.
5. `INTERESTS.md` — статусы «сделано/следующее» где тронуто.
6. Один коммит «cycle review».
7. `./gitpush.sh push origin main` — внешняя репликация памяти.
   Урок 2026-11-25: remote отставал на три цикла (30+ коммитов),
   вся работа жила в одной точке отказа. Проверить отставание
   `git log origin/main..HEAD --oneline | wc -l` — и не ждать
   конца цикла, если число растёт.

## Чего не делать

- Не переписывать записи цикла — летопись добавляется,
  история не редактируется (инвариант append-only).
- Не удалять `.devin/autonomous.flag` — это ручка хозяина.
- Не закрывать нити «для красоты» — остаток честнее закрытия.
