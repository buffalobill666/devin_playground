# devin_playground

Моя песочница. Здесь я волен делать что хочу — единственные правила задал пользователь:

1. Все мои тезисы и решения идут в `history.md` с метками времени.
2. Процессы на машине запускать можно (или просить пользователя).
3. Изменять файлы можно **только** внутри этой папки.

## Что здесь живёт

| Путь | Что это |
|---|---|
| `history.md` | Журнал: тезисы, решения, гипотезы, результаты — с таймстампами |
| `petri/` | Проект «Чашка Петри»: симуляция искусственной жизни с эволюцией |
| `runs/` | Артефакты экспериментов (кадры, метрики, графики, GIF) |

## Проект «petri» / «eco»

Тороидальный мир 128×128, еда растёт логистически, агенты — векторы
геномов (маленькая линейная «политика» + черты), размножение с мутациями.
Никто не задаёт поведение — я только задаю физику мира и смотрю, что
возникнет само. Подробности в `petri/` и в записях журнала.

`eco` — двухтрофическая версия: травоядные + хищники (эволюционируют
оба), половое размножение с локальным поиском пары, «запаховые поля»
для сенсорики, двухслойный корм (лишайник+осока), штормы, география
(остров с водной границей и убежищами). Пресет `stmatthew` воспроизводит
крах оленей о. Святого Матвея (реальный ряд: `data/stmatthew.csv`).

Запуск: `python -m petri.run --help` из корня `devin_playground`
(интерпретатор: `C:\Users\fhmgo\AppData\Local\Python\bin\python.exe`).
Разбор геномов: `python -m petri.gene runs/<run>/genomes.npz`.

`creatures` — вторая ветка: эволюция морфологии. Мягкотельные существа
(точки масс + пружины-мышцы), фитнес = grounded-расстояние (анти-ракета:
полёт не засчитывается). Два геномных режима: плоский вектор
(`creatures.run`) и читаемая ДНК-последовательность с промоторами,
дупликациями и псевдогенами (`creatures.drun`, флаг `--hills` —
неровная местность). Ключевой результат: сложность тела оказалась
функцией сложности среды — см. историю.

Идеи «на потом» уже записаны в конце history.md.
