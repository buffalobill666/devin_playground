# maps — картография несуществующего

Направление «вне мира» из `INTERESTS.md` (пункт E).
Процедурные карты выдуманных мест: берега, реки, топонимика.

## island.py

Октавный шум → высоты → радиальная маска (остров) → море/пляж/
холмы/вершины → реки спуском по градиенту (сток утолщает русло)
→ города на побережье и пик с именами слогового генератора.
Каждый запуск — новый остров: `py -3 maps/island.py` →
`island.png`.

## continent.py

Край континента (маска только на запад+юг — массив уходит
за край), биомы = высота × влага (пустыня/степь/трава/лес/
тайга/скалы/снег), реки, города. Топонимика **на языке mu**
(первое семантическое применение конлэнга): KUWAKA «море»,
POKAJIN «горы» (мн.ч.), SUMNOWAN «пески», KOMUWAN «леса»,
rija X — реки. Seed=7 — карта воспроизводима.

## transit.py (cycle4 i20)
Схематическая транзитная карта континента: 9 прибрежных
городов (greedy-расселение по пляжу), MST -> декомпозиция
на цепочки-линии, mu-имена станций и линий. Поверх — бледный
силуэт суши: схема сидит на своей географии. Пересадки
napa и sompe — точки ветвления дерева. Честный артефакт:
nammi у края карты — континент и в схеме уходит за рамку.

## mythos.py (cycle8 i20) — седьмой жанр
Хроника-география: «где что случилось». События расставлены
логикой террейна (основания в низинах, битвы у коридоров,
чудеса на пиках, храмы в чаще, голод в сухих землях, переход
у беrega) и соединены пунктирным путём в порядке времён —
география читается как рассказ. Имена на mu. Пергаментная
палитра, номера в кругах чернильных цветов по типу события.
