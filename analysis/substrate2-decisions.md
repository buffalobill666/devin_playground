# Субстрат-2: решения по открытым вопросам

*Итерация 5. Ответы на 7.1-7.3 учредительного документа.*

## 7.1 Интерпретатор — физика мира, не клетка

Биология сама так устроена: генетический код не эволюционирует,
он замороженная инфраструктура. Эволюционирует то, что геном
кодирует, не способ кодирования. Интерпретатор в среде —
не упрощение, а копия реального решения. Клеточный
интерпретатор вернул бы bootstrap-проблему без прибыли.

## 7.2 Геном — список генов с дупликацией, не байтовая лента

Байтовая лента возвращает алгебру целиком. Фиксированная
грамматика убивает открытость. Компромисс: геном — упорядоченный
список генов, каждый ген — тип + параметры. Мутации трёх
сортов, как в биологии:
- точечные (параметр гена дрейфует);
- делеции (ген выпадает);
- **дупликации** (ген копируется внутри генома — и копии
  дальше дрейфуют независимо). Дупликация-расхождение —
  настоящий двигатель инновации в биологии: новая функция
  рождается не из ничего, а из лишней копии старой. Байтовая
  лента ленты-1 не могла этого по построению. Ключевое
  отличие субстрата-2.

## 7.3 Копирование — физика по сигналу, с ценой против алгебры

Дилемма: копирование встроенное бесплатно — возврат дегенерата;
копирование полностью кодируемое — возврат bootstrap. Решение
гибридное и честное:
- **механизм** копирования — физика среды (интерпретатор
  умеет копировать геном с мутациями);
- **триггер** — кодируется геном: ген REPRODUCE с параметром
  порога. Нет гена — стерильность. Ген может мутировать порог,
  может выпасть, может дуплицироваться — тактика размножения
  эволюционирует, механизм нет;
- **цена**: cost = BASE + per_gene × L. Базовая большая —
  голый копировщик без добычи может родить однажды и умрёт.
  Per-gene малая — давление против раздувания генома, но
  слабое: дупликации не задавлены.

Проверка против приговоров ленты: (1) мутация при копировании,
не в жизни — да; (2) родитель остаётся, ребёнок новый —
да; (3) дегенерат платит BASE и голодает — геометрия
перевёрнута ценой, не запретом.

## Фенотип: минимальный словарь генов v1

- HARVEST(rate) — добыча энергии из локального пятна;
- MOVE(bias) — подвижность, таксис к градиенту ресурса;
- REPRODUCE(threshold) — сигнал копирования при запасе
  энергии выше порога;
- (метаболизм = константная цена жизни за тик, не геномная —
  физика, не тактика; осознанно: не даём эволюции отменить
  второй закон).

Всё. Три гена. Сложность должна РОДИТЬСЯ из дупликаций и
точечного дрейфа, а не быть вложена заранее — иначе мы
снова измерим собственную руку.
