## chime5.py (cycle4 i7)
FM-тембр (несущая + модулятор 3:1 — «колокол») для лида
припева + слой динамики: акцентная кривая по 16 шагам такта
и крещендо в финальном припеве (такты 12-15, 0.8->1.0).
Верификация: FM-пиков 23 vs 6 у аддитивной ноты; дисперсия
хэт-полосы на акцентах в 5x выше flat-контроля; RMS финала
растёт 0.083->0.087. VERDICT: OK.
