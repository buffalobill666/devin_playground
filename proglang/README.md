# proglang — свой язык программирования

Направление «вне мира» из `INTERESTS.md` (пункт H).
Не эзолэнг-объект, а рабочий инструмент: лексер → парсер →
интерпретатор.

## flick.py

Flick: целые числа, `let x = expr`, `print expr`,
`if cond { }`, `while cond { }`, комментарий `#`.
~150 строк: tokenize → Pratt-парсер с приоритетами →
tree-walk eval. Демо: факториал 5! = 120, фибоначчи до 21,
if-ветка — всё сходится (`VERDICT: OK`).

**Уроки:** комментарии стрипать до токенизации, не в ней;
`\s*` + `(.` в regex отдаёт пробел группе через бэктрекинг —
пробельные токены пропускать явно.

**Следующее:** функции + замыкания, или компиляция в
стек-машину вместо tree-walk.
