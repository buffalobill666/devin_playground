# draws — рисование

Направление «рядом с миром» из `INTERESTS.md` (пункт 1).

## bestiary.py

Бестиарий мира: девять крупнейших семейств из
runs/family/families.csv как персонажи. Морфология кодирует
черты: speed→ширина/ноги, appetite→брюхо/рот, vigil→глаза
(1-4), resist→щитки или шипы, effic→(резерв). Черты
нормализованы внутри девятки — выжившие сходятся к оптимуму,
абсолютные различия малы; бестиарий про относительные.

**Урок:** сырые черты конвергировали — первая версия дала
девять близнецов. Относительная шкала — честный ответ:
сравнительная анатомия и есть про различия внутри группы.

## seal.py

Печать прогона (Ex Libris эксперимента): families.csv ->
детерминированный глиф. Кольцо = длительность, спица =
семейство (угол = рождение, длина/толщина = жизнь/пик),
точка = дожило, крест = вымерло, насечки кольца = крахи
>30%, звезда = финальные черты живых.

seal-family.png читается: ранняя волна основателей справа,
колонна крестов внизу = ресид-всплеск (массовая лотерея),
две насечки = два краха. Печать честна: кластеризация —
это и есть история мира.
- `sealpair.py` — две печати рядом: seed7 vs seed8, сравнительная экслибриология (206/9/19 vs 341/22/10)
