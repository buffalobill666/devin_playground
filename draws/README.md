## bestiary.py

Бестиарий мира: девять крупнейших семейств из
runs/family/families.csv как персонажи. Морфология кодирует
черты: speed→ширина/ноги, appetite→брюхо/рот, vigil→глаза
(1-4), resist→щитки или шипы, effic→(резерв). Черты
нормализованы внутри девятки — выжившие сходятся к оптимуму,
абсолютные различия малы; бестиарий про относительные.

**Урок:** сырые черты конвергировали — первая версия дала
девять близнецов. Относительная шкала — честный ответ:
сравнительная анатомия и есть про различия внутри группы.
