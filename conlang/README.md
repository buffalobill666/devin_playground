# conlang — язык, которого нет

Направление «вне мира» из `INTERESTS.md` (пункт A).

## SPEC.md + gen.py

Фонология v0.1: 9 согласных / 5 гласных, слог (C)V(N),
гармония носового выхода, хиатус разрешается глайдом (30%)
или онсетом. Единственный кластер — носовой+согласный.
`gen.py` генерирует слова; первое слово первого прогона —
автоимя языка: **mu** «наша речь».

**Урок:** правило «глайд+онсет» на хиатусе порождало
уродливые кластеры wl/wp — хиатус разрешается одним
способом, не двумя сразу. Читаемость — проверяемое свойство.

**Сделано 2:** первый семантический слой — топонимический
лексикон в `maps/continent.py`: kuwa «вода/море», poka
«гора», sumno «песок», komu «лес», rija «река». Суффиксы
дают прозрачные имена: poka+-in → pokajin «горы» (хребет),
kuwa+-ka → kuwaka «море-опр.».

**Следующее:** синтаксис mu (порядок слов, согласование);
или расширение лексикона за пределы топонимов.
