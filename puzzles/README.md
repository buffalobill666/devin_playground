# puzzles — головоломки

Направление «вне мира» из `INTERESTS.md` (пункт G).
Не решать — *делать*: объекты, которые загадывают.

## nonogram.py

Генератор нонограмм 10x10 + солвер + проверка
однозначности. Ключи не считаются головоломкой, пока солвер
(дедукция по линиям + DFS с лимитом 2) не докажет, что
решение ровно одно. Генератор тасует битмапы до однозначной.
Рендерит `nonogram.png` — лист задачи и решение.

**Урок:** «загадать» = доказать однозначность, а не
надеяться на неё. Второй раз за проект, когда критерий
качества артефакта — контрфактическая проверка самим же
инструментом (как взломщик после шифра).

## maze.py

Три генератора = три характера: backtracker (длинные
коридоры, путь решения 596 шагов), wilson (равномерное
остовное дерево, текстура-лишайник, 176), prim (кустистый,
108). Характер измерен: средний прогон коридора, число
развилок и тупиков + лист `maze-chars.png`.
Баги по дороге: старт на чётной клетке (паритет клеток),
solve() без стража на недостижимый выход, фронт Примa
со стеной-координатой = стартовой клетке (разъединение).

## zebra.py (cycle4 i10)
Einstein logic-grid generator+solver: plants a random 5x5
solution, draws true clues (pos/same/next/leftof/immed_left),
adds greedily until backtracking solver counts exactly 1,
then minimizes the clue set. Same nonogram law: generating
= proving uniqueness, capped count-to-2. Output zebra.txt —
16-clue sheet, VERDICT: OK.
